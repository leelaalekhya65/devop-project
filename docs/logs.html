Logs

The app writes one JSON object per line to stdout. Promtail ships those lines to Loki, and Grafana lets you query them.

Pipeline

  1. Promtail uses Docker service discovery and only picks up containers labelled logging=promtail.
  2. A JSON pipeline stage extracts level, path and status; level becomes a Loki label.
  3. In Kubernetes the loki-stack Argo CD app deploys Loki and a Promtail DaemonSet instead.

LogQL cheat sheet

# all app logs
{container="webapp"}

# only errors
{container="webapp", level="ERROR"}

# parse JSON and filter slow requests
{container="webapp"} | json | duration_ms > 300

# error lines per minute
sum(rate({container="webapp", level="ERROR"}[1m]))
