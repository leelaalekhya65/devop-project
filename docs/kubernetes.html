Kubernetes

A local kind cluster created by Terraform, the app deployed through a Helm chart, and Argo CD keeping the cluster in sync with Git.

Cluster

  • 1 control-plane node and 2 workers (terraform/main.tf, k8s/kind-config.yaml).
  • ingress-nginx and argo-cd are installed by Terraform's Helm provider.
  • Host ports 8081 and 8443 map to the ingress controller.
make tf-init
make tf-apply
export KUBECONFIG=$(cd terraform && terraform output -raw kubeconfig_path)
kubectl get nodes

All three applications have automated sync with prune and selfHeal enabled, so manual drift in the cluster is reverted to what Git says.

Namespace policies (k8s/namespace-policies.yaml)

  • ResourceQuota caps CPU, memory and pod count for the webapp namespace.
  • NetworkPolicy denies all ingress by default, then allows TCP 8080 to the app pods.
