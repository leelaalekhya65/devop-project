Docker

The app is packaged as a small, non-root image and run locally with Docker Compose together with the full observability stack.

The image

  • Base: python:3.12-slim, dependencies installed with --no-cache-dir.
  • Runs as UID 10001 (non-root), served by gunicorn with 2 workers.
  • Built-in HEALTHCHECK against /healthz.
docker build -t devops-platform/webapp:local app/
docker run --rm -p 8080:8080 devops-platform/webapp:local

Commands

make up        # docker compose up -d --build
make logs      # follow app logs
make down      # stop and remove volumes
Credentials such as the Grafana admin password come from .env, which is git-ignored. Copy .env.example to get started.
