DevOps Platform

A complete, runnable DevOps project: containerised app, Kubernetes with Helm and Argo CD, Prometheus/Grafana/Loki observability, Terraform and Ansible automation, and CI/CD on GitHub Actions. Everything runs locally; no cloud account is needed.

Docker

Image build, non-root runtime, Compose stack with load generator.

Kubernetes

kind cluster, Helm chart, Argo CD GitOps, network policies.

Observability

Metrics, alerts and Grafana dashboards.

Logs

Structured JSON logs shipped to Loki, with LogQL examples.

How a change reaches the cluster

git push→ GitHub Actions CI
test, lint, build→ CD: push image to GHCR→ bump tag in Helm values→ Argo CD syncs→ Kubernetes rollout

Quick start

cp .env.example .env     # or: make keys  (also generates the SSH key pair)
make up                  # app + Prometheus + Loki + Grafana
# App        http://localhost:8080
# Prometheus http://localhost:9090
# Grafana    http://localhost:3000   (credentials from .env)
